# AKI Audio — versión web (Cloudflare Pages)

Versión estática de AKI Audio: todo se procesa **en el navegador**, sin servidor y sin subir la música.

- `index.html` — pantalla para elegir la canción.
- `player.html` — el reproductor y convertidor (tono, velocidad, recorte, MP3/OGG/WAV).
